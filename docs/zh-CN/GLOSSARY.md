# 术语表

千凝 Agent 是中文优先的：`docs/zh-CN/spec` 才是我们自己的读者与贡献者真正在读的那一面。本文件把要紧的术语固定下来，让译者（无论是人还是模型）不必**每页重新决定一次**。

## 已强制执行的规则

`docs/scripts/check-locales.mjs` 只对**可判定**的错译判失败 —— 命中必是缺陷，而不是风格意见：

- `Electron 主要` —— 英文源写的是 "Electron main"（主进程），应写作 `Electron 主进程`。`主要` 是「mainly」，那是另一句话。

上表其余各条是**指引，不是闸门**：剩下的漂移属于风格问题，而一条能匹配到合法句子的规则会让闸门变成噪音，久了就没人看。

## 新增规则的条件

只有当英文源与中文**就一个事实产生分歧**、且**任何合法中文句子都不会包含该禁用形式**时，才新增规则。同一个改动里要把术语补进上表，并扩展 `docs/scripts/check-locales.test.mjs`。

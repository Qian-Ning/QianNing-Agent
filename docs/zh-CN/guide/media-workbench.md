# 媒体工作台

在媒体工作台，写提示词、设定参数并看着产出落地的是你，而不是 Agent。它是侧栏页脚里的一等页面，紧挨着设置，也是唯一可以用手工方式配置一次生成的地方。

设置与工作台各管一段：设置负责「哪些模型有资格生图或生视频」，工作台负责「跑一次」。在这里选的模型只为当次运行生效，绝不写回设置，因此「我常用的模型」和「我此刻正在试的模型」始终是两个独立的决定。

一次运行不需要任何对话。打开工作台，描述你要什么，生成即可；产出是一份属于你的文件，而不是被塞进一个你必须一直保留的会话里的一条消息。

## 打开工作台

在侧栏页脚选择工作台图标（图片图标）。页面是两栏：左侧**创作区**，右侧**结果区**。**生图 / 生视频**切换直接位于页面标题下方，是页面提出的第一个决定。

生图与生视频是两种不同的活，因此各自保留自己的提示词、结果与历史。切换标签不会把提示词或首尾帧带到另一边。

## 选择模型

**模型**会打开一个分组、可搜索的菜单。首行跟随设置里的默认模型，下面的行按服务商分组。

- 菜单受当前标签限定：生图标签页只列渲染图像的模型，生视频标签页只列渲染视频的模型。
- 你在设置里标记过的模型按原样采信；其他模型必须在自己的 id 里带有生图或生视频家族名才会出现。
- **本机**服务商不受这条按名判断的约束，因为自建服务器是用文件名给模型命名的。详见下方**模型兼容性**。
- 没有配置任何合格模型时，菜单退化为单一的**去设置**，**开始生成**保持禁用。

控件下方那一行会写明实际将运行的服务商与模型 id。

## 参数

这些控件由运行时用于校验的同一批常量限定，因此页面不会提供一个请求会拒绝的值。

| 参数 | 生图 | 生视频 |
|---|---|---|
| 数量 | 1–4，按数字键入并校验 | 1–4，按数字键入并校验 |
| 比例 | 1:1 · 4:3 · 3:4 · 3:2 · 2:3 · 16:9 · 9:16 · 21:9 · 9:21，另有**服务商默认** | 16:9 · 9:16 · 1:1 · 4:3 · 3:4 · 21:9，另有**服务商默认** |
| 分辨率 | **智能** · 长边 512 到 4096 px，另有自定义 `WIDTHxHEIGHT` | **智能** · 480p · 720p · 1080p · 2K · 4K，另有自定义 `WIDTHxHEIGHT` |
| 时长 | — | 预设 2–15 秒；默认 8 秒 |
| 参考图 | 最多 4 张，经 multipart edits 端点发送 | — |
| 首尾帧 | — | 首帧、尾帧（尾帧需先有首帧） |

比例与分辨率是两个独立的控件，而不是一个。16:9 的 720p 与同一比例的 1080p 是两个不同的请求。两者分别选择，页面会在任何内容离开本机之前，显示组合后将要发送的尺寸。生图分辨率按长边命名（`3:2` + `1536` 即 `1536x1024`）；生视频档位按 `720p` 那样按短边命名（`16:9` + `720` 即 `1280x720`），因此同一档位的竖屏片段与横屏片段承载等量的画面。

**智能**是默认分辨率，且完全不发送尺寸。不同服务商接受的档位集合不同，而服务商可能按它确实支持的最近档位计费，因此在模型没有 480p 档时选了 480p，可能被按 720p 收费。智能把尺寸交给模型自身的默认值，它总是被接受。比例的**服务商默认**同样把这个选择交给模型。非法的自定义尺寸会就地报告并阻止提交，而不是被发出去。

数量在键入过程中是校验而非夹取：只收数字，且 1 到 4。零、五、小数、字母或空框都会就地报告并阻止提交，而不是被静默改写；离开该字段则把它确定为最接近的允许值。

## 参考图与首尾帧

**参考图**（生图）最多接受四张图片，把一段纯文字提示变成一次编辑。这样的一次运行会发往 multipart edits 端点。

**首尾帧**（生视频）接受首帧、尾帧，或两者都要。尾帧保持禁用，直到设置了首帧，并在该行写明原因。兼容 API 前面的网关可能给这两个部件起不同的名字；**高级**折叠项暴露这两个字段名，默认是 `input_reference` 与 `last_frame`。

## 成本、进度与取消

视频按秒计费，因此一次视频运行会在提交按钮旁写明 `片段数 × 时长 = 总秒数`，在发送任何内容之前，并在运行头里再写一次。生图运行写明请求次数。两个数字都不是关于金额的估算 —— 应用没有价格表 —— 也都没有声称是。

每一个被请求的产出从运行开始的那一刻起就有自己的卡片 —— 排队、渲染中，然后是结果 —— 按请求顺序排列，因为一个批次会乱序完成。**取消**通过与 Agent 工具相同的取消路径终止该次运行，但已经发送给服务商的片段可能仍会完成并仍然计费；取消无法作出别的承诺。

## 结果、预览与复用

生图结果从文件本身渲染缩略图，点击打开灯箱，可前后翻看整批，Escape 关闭。生视频结果是标明容器与时长的文件卡片；工作台不内嵌播放器，因此播放属于操作系统。

每一份跑完的结果都带**保存到…**与**打开所在文件夹**，生图与生视频一视同仁，因为只存在于应用内部的文件还不是你拥有的文件。任何生图结果都能用**用作参考图**推回参考图行，以便继续迭代。

## 渲染写到哪里

一次工作台运行拥有它自己的产出：图像落到 `<数据目录>/generated/image`，视频落到 `<数据目录>/generated/video`。正式版默认以 `~/.qianning-agent` 作为数据目录。

每个产出会在文件旁边的 `index.json` 里记录一次 —— 能力、路径、结果、提示词、模型、尺寸、错误码和时间 —— 因此媒体库跨重启仍在，早先记录的渲染会像刚刚跑完的一次运行那样在结果面板里打开。成功的运行记录它写出的文件；失败或被取消的运行不记录文件，但会记录原因，因此空结果也有一行而不是一片空白。记录列表是有界的；文件不是。

结果区下方的**历史**列出该能力已记录的运行（新的在前），加上本次会话的运行。

## 清理与找回

**历史**的每一行都带自己的移除控件，整个列表也可以被清空或在磁盘上打开。

- **移除**单条会先问一句：*从历史中移除这一条？文件会移入系统回收站，仍可找回。*
- **清空**会问：*清空全部历史？所有记录都会被清除，文件移入系统回收站。此操作在应用内无法撤销。*
- 两者都会把文件移入系统**回收站**，而不是直接删除，因此误删可以从那里找回；即使回收站拒绝某个文件，移除仍会照常完成。
- **文件夹**按钮会打开媒体库目录本身。

历史头部会显示还剩多少空间 —— *已保留 N / 500 条* —— 并附说明*这里只保留最近 500 条生成记录，更早的记录会退出列表，文件仍留在磁盘上。*

## 模型兼容性

工作台以 OpenAI 兼容形状与服务商通信：图像走 `POST /v1/images/generations`，视频走 `POST /v1/videos` 并按 job id 轮询。根 base URL 会补上 `/v1`；显式路径前缀会保留。

- **本机**服务商 —— 环回地址，或诸如 `192.168.*`、`10.*`、`172.16–31.*` 的私有地址 —— 会在模型菜单里标记为**本机**，并豁免按名判断能力的检查，因为它的模型名就是文件名，否则会被隐藏。内置预设包含位于各自默认本机地址上的 **Ollama**、**LM Studio** 与 **LocalAI**。
- **ComfyUI** 与 **Stable Diffusion WebUI** 暴露的是自己的原生 API，不是 OpenAI 形状。它们需要前面加一层兼容包装或代理；工作台无法只凭地址直接调用它们。见[本机生成桥](/zh-CN/guide/local-generation-bridge)。

Agent 工具 `GenerateImages` 与 `GenerateVideos` 由同一批请求构造器支撑，因此工作台的一次运行与工具的一次运行会产生同类请求。

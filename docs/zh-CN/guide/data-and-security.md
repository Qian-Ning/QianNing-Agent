# 数据、隐私与安全

「本地优先」描述的是归属与路由，不是绝对隔离。千凝把应用状态保存在本机，并把模型请求发往你自己配置的服务。工具、插件、MCP 服务、外部链接和模型渲染的媒体，在你使用它们时仍然会跨出本机边界。

## 数据目录

正式安装使用 `~/.qianning-agent`；开发构建使用 `~/.qianning-agent-dev`。`PI_DESKTOP_DATA_DIR` 可以替换根目录，供受控的开发与测试环境使用。

```text
~/.qianning-agent/
├── pi.sqlite                 # 索引与结构化应用状态
├── sessions/*.jsonl          # 完整、可直接阅读的会话记录
├── sessions/*.inflight.json  # 流式输出期间的临时检查点
├── secrets/                  # 加密后的密钥数据与机器密钥
├── attachments/              # 按内容寻址的会话附件
├── plugins/                  # 已安装的插件代码与插件数据
├── logs/                     # 本地应用、宿主与运行时日志
├── review-changes/           # 有界的文件审查与回滚证据
└── scratch/<sessionId>/      # 单个会话独占的临时文件
```

SQLite 与会话记录的写入由 Rust host-core 独占，Renderer 与 Node sidecar 都不会直接打开数据库。

## 什么会离开本机

| 动作 | 网络目的地 |
|---|---|
| 发送一条提示 | 该会话选定的模型服务或网关 |
| 刷新模型目录 | 已配置的服务接口地址 |
| 安装或刷新技能 / MCP 目录 | 来源地址与被允许的文档地址 |
| 使用具备网络能力的 MCP 服务或插件 | 由该扩展自行选择的目的地 |
| 渲染助手消息中的远程媒体 | 消息中点名的远程 `http(s)` 主机 |
| 检查更新 | 固定的 QianNing Agent GitHub Releases 源 |

已完成助手消息里的远程图片、音频和视频**无需点击即可加载**，因此该远程主机可以观察到本机的公网地址。链接经过地址校验后交由操作系统浏览器打开。

## 密钥

服务、MCP 与同步用的凭据由 host-core 管理。Renderer 只拿到「已配置 / 未配置」状态，永远不会为了显示而拿到明文。日志与审计写入都会执行密钥脱敏。

Electron `safeStorage` 保护本地加密数据，但千凝目前**没有接入独立的操作系统钥匙串后端**。以同一操作系统用户运行、且能读取应用数据目录的进程，仍在本地威胁模型之内。磁盘加密、受保护的用户账户，以及常规的操作系统访问控制依然重要。

## 工作区与权限

文件工具默认作用于持久会话所绑定的项目，相对路径在该工作区内解析。工作区与会话临时目录之外的路径需要显式的「外部路径」许可；拒绝、取消或超时都不会执行。

高风险操作由 Rust host-core 判定，而不是由 Renderer 状态决定。权限请求 120 秒后过期，并以失败关闭。会话级授权保存在内存中，并按工具名限定范围。

Bash 以当前操作系统用户的权限运行。千凝会约束它的工作目录、超时、输出、取消与审计路径，但它**不是操作系统级容器**。

## 插件、技能与 MCP

- 技能是加载进 Agent 上下文的 Markdown 指引。请把它当作来自发布者的指令来审视。
- MCP 服务会暴露工具，并可能自行发起网络或系统调用。无论服务自报的风险等级如何，用户配置的 MCP 工具都由宿主按中风险对待。
- 应用市场插件目前运行在独立工具进程中，但可能使用原生 Node 内置模块。在能力沙箱与可信发布者签名落地之前，请把已安装的插件代码视为具备用户权限的代码。
- 目录传输哈希在提供时用于校验下载字节，但它**不证明发布者身份**。

只从你信任的来源安装扩展；当扩展能够访问有价值的数据时，检查它申请的权限与源码。

## 备份与恢复

要做完整的本地备份，请先完全退出千凝，再复制 `~/.qianning-agent`。这样可避免 SQLite、WAL 与正在追加的会话记录被复制于不同的时间点。

数据目录包含密钥与私密会话记录。备份的访问控制强度不应低于原账户。不要把整个目录附在问题报告里。

加密的 WebDAV 配置同步与会话备份是两件事。它可以携带选定的偏好设置与用户自有能力，但**不会同步对话历史或项目源码文件**。

## 删除数据

删除会话会通过 host-core 移除它的记录、临时目录和该会话的审查快照。卸载应用可能保留数据目录。若要清除全部本地应用状态：

1. 完全退出千凝，包括托盘进程；
2. 先备份你需要保留的内容；
3. 删除 `~/.qianning-agent`；
4. 一并删除你另行配置的开发用或被覆盖的数据目录。

除非你保留了备份，否则此操作不可恢复。

## 报告安全问题

请遵循仓库 [安全策略](https://github.com/Qian-Ning/QianNing-Agent/blob/main/SECURITY.md) 中的私密报告渠道。不要在公开问题中包含有效凭据、完整私密会话记录或未经脱敏的本地路径。

权威实现契约是[安全规格](/zh-CN/spec/05-security/01-security)，存储细节见[数据存储](/zh-CN/spec/03-runtime/04-data-storage)，工具策略见[工具与权限](/zh-CN/spec/03-runtime/03-tools-and-permissions)。
